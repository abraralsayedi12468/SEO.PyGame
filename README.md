🎓 Exam Catcher — SEO PyGame Project

Exam Catcher is a school-themed interactive game built with Python and PyGame. The goal is to help a student earn a passing exam score by collecting academic items while avoiding distractions before time runs out.

Players control a student character using the left and right arrow keys. Academic items such as books, pencils, calculators, laptops, and backpacks add points, while distracting items subtract points. The game also includes special items: collecting a ⭐ star results in an automatic pass, while catching a 💣 bomb immediately ends the game.

As the game progresses, the difficulty increases by changing the speed, frequency, and types of falling items. Players can also access a settings menu to select their student character and view statistics such as games played, passes, total points, and best score.

💻 Programming Concepts

This project demonstrates several Python and game-development concepts, including:

Object-Oriented Programming (OOP) using Game and FallingItem classes
Functions and methods for organizing game behavior
PyGame event handling for keyboard and mouse input
Collision detection between the player and falling objects
Randomization for item generation
Game states for the start screen, settings, gameplay, and end screens
Score and difficulty tracking
Real-time game loops and rendering
🎮 How to Play

Use the ← and → arrow keys to move the student. Collect academic items to increase your score, avoid distractions and bombs, and try to earn at least 65% before the timer reaches zero.
